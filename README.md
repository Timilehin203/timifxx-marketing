# TimiFxx Marketing - Telegram Ads Marketing Solutions

A complete production-ready website for Telegram marketing services with customer ordering, order tracking, and an admin dashboard.

## Features

- **Customer Website**
  - Browse Telegram marketing services with current prices
  - Place orders directly on the website
  - Track order status with unique order number
  - Contact administrator when necessary

- **Admin Dashboard**
  - Private login with JWT authentication
  - Dashboard overview with order statistics
  - Order management (view, search, filter, change status)
  - Service management (change prices, activate/deactivate)

- **Technical Features**
  - PostgreSQL database with proper schema
  - Secure API with JWT authentication
  - Environment variables for sensitive configuration
  - CORS configured for production
  - Responsive dark modern design
